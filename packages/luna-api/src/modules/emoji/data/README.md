# Emoji data

Unicode Emoji 17.0 names, sequences and group keywords from
[emoji-test.txt](https://unicode.org/Public/17.0.0/emoji/emoji-test.txt), retained from
[old Luna at 9aa7d7e](https://github.com/dot-luna/luna/tree/9aa7d7e7aa48686d243bc1793f37ee9fd246ab58/src/luna-cli/insert/data).
Only fully-qualified sequences are included. Artwork paths are omitted; the menu
uses Noto Color Emoji. Keep the [Unicode license](LICENSE) with the data.

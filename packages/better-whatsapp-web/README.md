# Luna Better WhatsApp Web

Resize WhatsApp's sidebar, change message text size, and navigate unread chats.
Installed locally into Luna's Chromium profile by `luna configure chromium`.

Open WhatsApp and press `Ctrl+Alt+Down` for the next unread conversation.
Use **Aa** in the chat-list header for text size and shortcuts.

See [controls, build and tests](DOCS.md).

# Zen Browser

Install Zen and apply Luna's browser colors, UI and monospace fonts, square
corners, uBlock Origin, and Bitwarden to its existing default profile.

```sh
luna install zen-browser-bin
# On first install, open Zen once and close it before configuring.
luna conf zen
```

Close Zen before configuration; restart it afterward to apply the changes.
See [DOCS.md](DOCS.md) for profile selection, replaced files, and limitations.

# Code Comments

Repository-local guidance for accurate code comments, Rust API docs, module
overviews, and QML/bridge lifecycle explanations. It is installed in
`.agents/skills/code-comments/` with automatic discovery enabled.

```text
Use $code-comments to improve comments in packages/hocon/src/storage.rs.
Verify claims against callers and tests; preserve executable code.
```

See [SKILL.md](SKILL.md) for scope, placement, examples, and validation.
Adapted from [smartcmd/code-comments](https://github.com/smartcmd/code-comments).

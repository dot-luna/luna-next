# Luna installation

Prepare an Arch Linux user installation in `~/.local/src/luna-next`, install the
CLI, then apply Luna's package and desktop setup. Run as your normal user with
sudo access:

```sh
bash install/setup.sh
```

Use `install/install.sh` to install only the checkout, shared environment, and
CLI. See [DOCS.md](DOCS.md) for remote installation, reruns, and paths.

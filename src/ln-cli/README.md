# lnxt

Wallpaper commands for terminals, menus, and other apps. Uses the shared
[`luna-next` library](../../packages/luna-next/README.md).

Install to `~/.local/bin/lnxt` from the repository root:

```sh
mise run install:ln-cli
lnxt wallpaper list --json
```

See [DOCS.md](DOCS.md) for commands, configuration, and JSON responses.

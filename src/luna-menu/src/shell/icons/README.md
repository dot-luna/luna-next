# Menu icons

Use free Hugeicons Stroke Rounded icons for Luna UI. These SVGs come from
[`@hugeicons/core-free-icons` 4.4.0](https://www.npmjs.com/package/@hugeicons/core-free-icons/v/4.4.0).
The filenames follow the upstream export names. `currentColor` is stored as white
so Qt can tint the vectors with the selected theme. Keep the [MIT notice](LICENSE.md)
when adding or redistributing icons. No icon font or network request is needed.

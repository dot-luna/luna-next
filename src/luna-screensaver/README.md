# Luna Screensaver

A themed clock that appears on idle and dismisses on keyboard or mouse input.

With the [Luna CLI](../luna-cli/README.md) installed:

```sh
luna install luna-screensaver
luna screensaver start
```

Settings use `~/.config/luna/screensaver.jsonc`. See [DOCS.md](DOCS.md) for
configuration, commands, and tests.

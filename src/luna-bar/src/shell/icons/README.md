# Bar icons

Free Hugeicons Stroke Rounded icons from
[`@hugeicons/core-free-icons` 4.4.0](https://www.npmjs.com/package/@hugeicons/core-free-icons/v/4.4.0).
Filenames follow the upstream export names. `currentColor` is stored as white so Qt
can tint the vectors with the theme. Keep the [MIT notice](LICENSE.md) when adding
or redistributing icons. Only icons the bar uses by default are bundled; settings
may point workspace icons at any absolute `.svg` path.

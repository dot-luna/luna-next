# Arch installer

A separate Bash installer for Arch with Luna's defaults and a basic Hyprland desktop.

Boot the official Arch ISO in UEFI mode, connect to the internet, and run Luna's
[CLI bootstrap](../../install.sh) as root. Then:

```sh
bash ~/.local/src/luna-next/arch-install.sh
```

See [DOCS.md](DOCS.md) for prompts, defaults, limitations, and checks.
